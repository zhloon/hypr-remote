# HyprRemote - 跨平台对等远程控制客户端

专为 **Wayland & Hyprland** 设计的高性能跨平台远程控制软件，类似 **AnyDesk / RustDesk / TeamViewer** 的使用体验。
客户端在 **Windows / macOS / Linux (Hyprland)** 上完全统一：**每个客户端既是被控端，也是主控端，无需单独运行服务端脚本，通过 6 位连接码一键连接**。

---

## 🌟 全新特性 (v2.0 对等架构)

- 🔄 **对等统一客户端 (Symmetrical)**：
  - 双方运行同一个 App 即可。
  - 左侧展示「本机连接码」与「临时验证码」（用于被控）。
  - 右侧输入对方「伙伴连接码」（用于发起控制）。
- 🔑 **6 位数字连接码**：
  - 无需再手动记忆或输入 IP 地址与端口。
  - 基于局域网 UDP 广播自发现协议，自动在后台解析连接码对应的局域网主机。
- 📡 **局域网设备雷达**：
  - 界面下方实时罗列局域网内所有在线的 HyprRemote 设备，点击即可自动填入连接码。
- 🖥️ **零黑屏超低延迟画面流 (MJPEG Stream)**：
  - 彻底解决传统 WebRTC 在无外网环境下的 SDP 协商黑屏、编解码器缺失和握手失败问题。
  - 在 Linux/Hyprland 上利用 `grim` 原生截屏；在 macOS 上利用 `screencapture`；支持高帧率平滑回放。
  - 即使在权限未授予的极端环境下，内置守护进程也会生成动态画面保证连接不中断。
- 🎯 **双向键鼠事件注入**：
  - 鼠标支持绝对坐标与 Pointer Lock（相对位移）双模式。
  - macOS 映射为系统级 `CGEvent`；Linux/Hyprland 支持 `hyprctl dispatch` 及 `ydotool` / `/dev/uinput`。

## 🚀 启动与使用指南

### 1. 启动客户端 (macOS / Linux / Windows 相同)

打开终端执行：
```bash
cd /Users/zhlon/hypr-remote/client/src-tauri
cargo run
```
*(或直接执行编译好的可执行文件 `target/debug/hypr-remote-client`)*

---

### 2. 如何连接

1. **测试自我回环（在本机立即验证画面与控制）**：
   - 启动软件后，查看左侧的「本机连接码」（例如：`742 819`）。
   - 在右侧输入框填入你自己的连接码：`742 819`。
   - 点击 **「🚀 立即连接」**，即可立即看到自己的桌面画面并测试鼠标移动！
2. **两台电脑跨平台互控（例如 Mac 远程控制 Hyprland，或 Hyprland 控制 Mac）**：
   - 两台电脑在同一个局域网（Wi-Fi 或有线）内打开软件。
   - 界面下方「局域网在线设备」会自动显示对方的主机名和连接码。
   - 点击对方设备或直接输入对方的 6 位连接码，点击连接，秒级进入远程桌面！

### 3. 特性与操作指南

| 功能特性 | 说明 |
| :--- | :--- |
| **纯粹 1:1 原生键鼠输入** | 彻底移除所有客户端快捷键劫持与重映射；用户键盘输入什么按键，远端就直接接收什么按键（完全保留所有 IDE、终端、游戏与系统快捷键） |
| **双向剪贴板同步** | 无论是本地复制远端粘贴，还是远端复制本地粘贴，250ms 无感瞬时同步（支持 Mac `pbcopy`/`pbpaste` 与 Linux Wayland `wl-clipboard` / X11） |
| **WebGPU 硬件渲染加速** | 采用 WebGPU / wgpu 着色器管线与纹理直传（自动降级 WebGL2），实现低延迟、高流畅度的 60~120 FPS 画面呈现 |
| **全屏沉浸操作** | 顶栏一键切换沉浸式全屏，鼠标点击画面直接操作 |
